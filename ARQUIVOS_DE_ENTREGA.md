# Arquivos de Entrega

## Projeto completo e gerador online

Arquivo:

`arquivos_finais_github.zip`

Use este pacote para atualizar o repositório principal e o aplicativo Streamlit. Ele contém o gerador online, a coleta offline, o projeto Android, o workflow do APK, o modelo Word, os guias e o manual.

## Android

Arquivo:

`agres_offline_android_project.zip`

Use este pacote para gerar o APK pelo GitHub Actions. Extraia e envie as pastas `.github`, `android-apk` e `docs` mantendo exatamente essa estrutura. Depois, execute o workflow `Build Android APK`.

Versão esperada:

`Agres Offline 1.0.18`

## iPhone e iPad

Arquivo:

`agres_offline_iphone_ipad_pwa.zip`

O iPhone/iPad utiliza uma PWA, não um APK. Extraia e publique a pasta `docs` pelo GitHub Pages. Abra o link HTTPS no Safari e use `Compartilhar > Adicionar à Tela de Início`.

## Manual

Arquivo:

`MANUAL_UTILIZACAO_RELATORIOS_TECNICOS_AGRES_ABNT_1.0.18.docx`

Manual separado por plataforma, com capítulos próprios para APK Android e iPhone/iPad.
